# 回滚

## 原则

先恢复服务可用，再调查原因。

## 步骤

1. **只**回滚本应用 `<STACK_NAME>`：将 `<IMAGE_TAG>` 改回发布前版本  
2. Update / Redeploy（仍只 pull 容器仓库，不本地 build）  
3. 确认本应用各 `<SERVICE_n>` 正常；**不要**重启无关 Stack「碰运气」  
4. 若改过本应用 Cloudflare DNS 或 NPM：只改回本应用记录/Host  
5. 本应用冒烟 + 抽查既有应用  
6. 若误动了共享网络或其他应用：先按 `09-isolation-safety.md` 恢复共享资源，再处理本应用  

## 数据库

- 已执行的迁移不一定可自动回滚；迁库前务必备份  
- 日常只升镜像、未迁库时，回滚镜像通常足够
